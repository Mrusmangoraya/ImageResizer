# ImageResizer
A Streamlit-based Passport Image Resizer that automatically resizes photos to 600×800 pixels and compresses them to under 25 KB, making them suitable for government portals, educational board admissions, online registrations, job applications, and other official document submissions.
# 🖼️ ImageResizer

A modern and easy-to-use **Streamlit** web application for resizing images and removing backgrounds using AI. Built with **Python**, **Pillow**, and **Rembg**, this project provides a clean interface for fast image processing without requiring any advanced editing software.

## 🚀 Live Demo

Deploy this project on Streamlit Community Cloud or run it locally.

**Repository:** [ImageResizer GitHub Repository](https://github.com/Mrusmangoraya/ImageResizer?utm_source=chatgpt.com)

---

## ✨ Features

* 📤 Upload images (JPG, JPEG, PNG)
* 📏 Resize images with custom dimensions
* 🎨 AI-powered background removal
* 👀 Instant preview of processed images
* 💾 Download the final image
* ⚡ Simple and responsive Streamlit interface

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/Mrusmangoraya/ImageResizer.git
cd ImageResizer
```

### 2. Create a virtual environment (Recommended)

Using Conda:

```bash
conda create -n image_env python=3.11
conda activate image_env
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```
